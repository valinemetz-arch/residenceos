    - GET /api/contracts/project/{projectId}

  app/api/contracts/contractor/[contractorId]/route.ts
    - GET /api/contracts/contractor/{contractorId}
    - Get all contracts for a contractor

  app/api/webhooks/docusign/route.ts
    - POST /api/webhooks/docusign

=== KEY WORKFLOW ===

ADMIN WORKFLOW:
1. Admin approves bid
2. Goes to /admin → Contract Management
3. Clicks "Send Contract"
4. Confirms project details
5. Contract sent to contractor via DocuSign
6. Contractor receives email with signing link

CONTRACTOR WORKFLOW:
1. Receives email "Contract Ready to Sign"
2. Logs into /contractor
3. Goes to Contracts tab
4. Clicks "Sign Contract"
5. Modal opens with instructions
6. Clicks "Sign Now in DocuSign"
7. Opens DocuSign in new window
8. Reviews and signs
9. Modal auto-updates on completion
10. Status changes to "Signed"
11. Can download signed PDF

=== BEFORE DEPLOYING ===

1. Run database migration:
   npx prisma migrate dev --name add_docusign_contracts

2. Configure DocuSign webhook:
   - URL: https://[YOUR_DOMAIN]/api/webhooks/docusign
   - Events: envelope-signed, envelope-completed

3. Test contract sending:
   - Go to /admin
   - Find approved bid
   - Click "Send Contract"

4. Test contractor signing:
   - Check contractor email for signing link
   - Click signing link
   - Sign contract in DocuSign
   - Verify status updates in portal

5. Verify email delivery:
   - Check contractor received signing email
   - Check admin received signed notification

=== API RATE LIMITS ===

DocuSign limits (varies by plan):
  - Token requests: ~50/minute
  - API calls: Varies
  - Token caching helps minimize requests

=== SECURITY ===

- Private key in environment variables only
- Token cached for 55 minutes
- SMTP over TLS for emails
- Signing links expire after 90 days
- Database audit trail maintained

=== TESTING ===

Send contract:
  curl -X POST http://localhost:3000/api/contracts/send \
    -H "Content-Type: application/json" \
    -d '{"projectId":"pid","contractorId":"cid",...}'

Check status:
  curl http://localhost:3000/api/contracts/{envelopeId}/status

=== COMMON ERRORS ===

Missing credentials → Check .env.local for all 4 variables
Token error → Verify Integration Key + Private Key match
Template not found → Check template ID in DocuSign
Webhook not received → Configure URL in DocuSign account settings
